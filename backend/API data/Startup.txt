To deploye INCAyur Backend 

1.create database "incayur", create "incayurdocs" folder in webapps/ROOT (for image uploads)
2.create "builds" folder in incayur/backend folder.(for generation of builds and war)
3.copy  inc-build.sh in "builds" folder , NOTE: do not check in(commite) Builds folder.
4.open git bash 
	
	1. run command ," sh inc-build.sh stop " ---------to Stop server
	2. Copy the generated ".war" file from "D:\PROJECTS\INCAyurveda\incayur\backend\inc-common-rest\build\libs\INCAyurManager.war"
	    and paste that into webapps folder and start tomcat.
	
		Note : logs generated inside builds folder with extention "rest.out" , different log files for different rest packges. 
			* do not delete ".molepids" file
	2. run the necessory api

5.log file generate path
  C:\opt\incAyur\logs
